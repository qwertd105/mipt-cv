# Объектная детекция с использованием DETR и синтетических данных

Этот проект демонстрирует использование трансформерной архитектуры (DETR) для задачи детекции объектов, а также исследует влияние синтетических данных (Stable Diffusion + ControlNet) на качество обучения.

## Fine-tuning DETR

Была взята предобученная модель `facebook/detr-resnet-50` и дообучена на 10 выбранных классах из COCO:
`['person', 'car', 'dog', 'cat', 'chair', 'bottle', 'laptop', 'cup', 'bus', 'truck']`.

**Параметры обучения:**
*   Epochs: 5
*   Batch Size: 16
*   Learning Rate: 5e-5 (backbone lr: 5e-6)
*   Optimizer: AdamW

Наблюдения:
*   **Total Loss** стабильно снижался и к 10-й эпохе достиг значения ~X.XX.
*   **Classification Loss** падает быстрее, модель быстро учится различать типы объектов.
*   **BBox Loss** снижается медленнее, так как точная локализация требует больше итераций.

## Синтетические данные

Для улучшения детекции редких классов (в эксперименте был выбран класс **Cat**) использовался пайплайн **Stable Diffusion + ControlNet Canny**.

**Алгоритм:**
1.  Берется исходное фото кота.
2.  Строится Canny Edge Map (контур).
3.  Генерируется новое изображение по промпту: *"A high quality photo of a cat, cinematic lighting"* с сохранением геометрии.


Синтетические данные были добавлены в train-set, после чего модель была переобучена с нуля.

## Результаты Ablation Study

Сравнение базовой модели и модели, обученной с добавлением синтетики (+100 изображений котов).

| Metric | Baseline Model | Augmented Model  |
| :--- | :--- | :---  |
| **mAP** (IoU=0.5:0.95) | 0.452  | 0.468  
| **mAP50** (IoU=0.5) | 0.610  | 0.635  | 

### Выводы
1.  Добавление синтетики помогло улучшить детектирование класса `Cat`, особенно в сложных условиях освещения (так как SD генерирует разнообразные фоны).
2.  Общий mAP вырос незначительно, так как синтетика добавлялась только для одного класса.
